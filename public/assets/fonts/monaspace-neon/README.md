Monaspace Neon variable webfont, v1.400, from GitHub Next.

Source: https://github.com/githubnext/monaspace/tree/v1.400/fonts/Web%20Fonts/Variable%20Web%20Fonts/Monaspace%20Neon

`MonaspaceNeonVar.woff2` is the unmodified upstream `Monaspace Neon Var.woff2`,
renamed for the asset URL. The accompanying SIL Open Font License is in `OFL.txt`.

`VeritasMono-latin.woff2` is a generated common-character subset, renamed to respect the reserved font names. It retains the original license, copyright notices, variable axes, and OpenType features. The original file remains available as a fallback for other characters. Regenerate the subset and shared CSS with `scripts/subset-fonts.py`.
